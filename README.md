# ChatDeck Legacy (Lite Edition)

Простой, лёгкий и быстрый Twitch-чат оверлей с поддержкой 7TV смайликов и значков для OBS.

## Что такое ChatDeck Legacy?

**ChatDeck Legacy** — это легковесная версия ChatDeck, созданная по принципу «включил и стримь»:
- **Настройка в 1 клик**: достаточно ввести только никнейм канала на Twitch — никаких сложных регистраций в консоли разработчиков Twitch или DonationAlerts.
- **Поддержка 7TV**: глобальные и канальные смайлики загружаются автоматически.
- **Значки Twitch**: бейджи сабов, модераторов, VIP и стримера отображаются из коробки.
- **Выделение ролей**: визуальная подсветка сообщений стримера, модераторов и VIP.
- **Реальный статус и аптайм стрима**: автоматическое определение выхода в эфир, таймер длительности стрима и количество зрителей онлайн.
- **Полная кастомизация**: шрифты, цвет текста, прозрачность и цвет плашки, интервалы между сообщениями, размер смайликов, скрытие старых сообщений.
- **Компактный интерфейс**: окно приложения оптимизировано до мини-виджета, снижено потребление оперативной памяти (тяжёлый встроенный предпросмотр удалён, стилизация настраивается через быстрое модальное окно с микро-превью).

## Установка и запуск

1. Скачайте последнюю версию из раздела [Releases](https://github.com/neshpaki4/chatdeck/releases).
2. Запустите `ChatDeck Legacy Setup.exe` или портативную версию `ChatDeck Legacy.exe`.
3. Введите никнейм вашего канала на Twitch и нажмите **«Сохранить и подключить»**.
4. Скопируйте ссылку (по умолчанию `http://localhost:6767`) и вставьте её в OBS как источник «Браузер» (рекомендуемый размер: 450×700).

## Разработка

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm start

# Сборка дистрибутива
npm run dist
```
